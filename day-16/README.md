# Day 16: OOP Coffee Machine

Run `main.py`. Type `espresso`, `latte`, or `cappuccino`. Type `report` to see what's left, or `off` to stop. Coins are quarters, dimes, nickles, and pennies.

`menu.py`, `coffee_maker.py`, and `money_machine.py` are the course's provided classes (unchanged). All of my code is in `main.py`.

The course's class documentation is in [coffee-machine-docs.pdf](coffee-machine-docs.pdf).
