# Day 19: Turtle Race

Run `main.py`. It needs Python's `turtle` module, which opens a Tk window, so use a desktop Python that can show a GUI.

A popup asks which turtle will win. Enter a color: `red`, `orange`, `yellow`, `green`, `blue`, or `violet`. Six turtles line up at x = -230 and each takes a random step of 0 to 10. The first turtle past x = 230 wins. The terminal prints whether the bet won. Click the window to close it.
